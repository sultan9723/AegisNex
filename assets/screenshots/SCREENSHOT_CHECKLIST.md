## General Screenshot Guidelines

1. **Resolution**: 1440×900 px (standard laptop). Also provide @2x (2880×1800) for retina.
2. **Browser**: Chrome/Edge in dark mode. No dev tools, bookmarks, or extensions visible.
3. **Data**: Use realistic demo data — container names like `api-gateway`, `auth-service`, `postgres-primary`.
4. **State**: Show a healthy system with 1-2 active incidents for visual interest.
5. **Format**: PNG lossless. Compress with `pngquant` or similar.
6. **Naming**: kebab-case. Match the placeholder file names exactly.
7. **Placement**: All screenshots in `assets/screenshots/`.
8. **Annotate**: If needed, use subtle numbered callouts (white circles, 24px, `rgba(0,0,0,0.7)` background).
